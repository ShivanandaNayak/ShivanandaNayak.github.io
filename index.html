📴 Use without internet

Open an app once while online, then add it to your Home Screen. After that it opens from the icon like a normal app, even with no internet.

🍎 iPad / iPhoneOpen in Safari → tap Share ⬆️ → Add to Home Screen
🤖 AndroidOpen in Chrome → tap ⋮ menu → Add to Home screen / Install app
💻 LaptopOpen in Chrome or Edge → click the Install icon in the address bar

💾 Progress is saved only on that device. Use Settings → Backup in each app now and then to keep a copy.
